# 补充实验：一致性检查、配对置信区间、COCOXGEN

## 已冻结的方案

- 官方数据 https://huggingface.co/datasets/heikeadel/cocoxgen
- 论文 https://aclanthology.org/2025.genaidetect-1.2/
- 版本 c336ad187c2ab298ce825df65088bdacbae104f6；文件清单见 dataset_lock.json。
- 1061 COCO val2017真图 + 4244合成图，完整使用，不按模型分数筛样本。
- 论文报告COCO/Fooocus为640×480，SDXL为1152×864；脚本逐图记录实际尺寸，并核对真图元数据。
- 主要结果：四个“真图 vs 生成器×提示长度”平衡测试单元等权平均，再对三个固定模型种子平均；同时输出每个模型及每个单元的结果。全量普通准确率仅作次要指标，因为假图占80%。
- 九个既有模型、原验证阈值、原验证温度、原cap128_jpeg95预处理保持不变；不训练、不拟合、不挑种子。
- 由官方目录映射real=0/fake=1，不沿用HF imagefolder中fooocus=0的目录编号。
- COCO真实图片从官方S3存储桶HTTPS下载，不关闭TLS证书验证；模型不会访问网络。

## 一致性检查

每个旧测试域（seen、GLIDE、VQDM、CIFAKE）按固定哈希规则抽32真+32假，共256张；九模型全部重算，共36项对照。
GenImage三域的相对路径原清单与绝对路径合并清单逐图核对预处理张量，要求完全一致。
再与已保存预测比较；预先固定最大概率误差0.002（容纳不同batch布局下AMP差异），所有决策翻转都会报告，离原阈值超过0.002的翻转将停止。
这不是逐位相同承诺，也不是对未抽样图片的全量一致性证明。

## 置信区间

- 2000次配对cluster bootstrap，随机种子20261108，95%百分位区间。
- 旧holdout只检验预先选定clean、resize_050、blur_r10三个条件；按1000语义类别成组，保留每类多个生成器/真假图关联。
- V2减ResNet的差值使用完全相同重采样，另给每个指标跨三个条件的Bonferroni区间。
- 新外部测试按COCO原图编号成组，四个变体、所有模型和三个种子共用抽样；若有完全相同图片跨COCO组，会联合这些组，但不删原测试行。
- 种子是固定已训练模型，不作为独立图片重复样本；区间描述条件于这些模型的测试抽样不确定性，不包含新训练随机种子的不确定性。
- 单模型和模型家族区间均保存；seed_sample_sd继续单独报告。

## 作业依赖

CPU旧结果CI与CPU下载/数据审计并行。
CPU数据审计成功 → 一次L20 GPU作业（九模型一致性及全部外部推理）。
GPU与旧结果CI都成功 → CPU外部CI与汇总打包。
只有一次GPU申请。申请时限是上限，不是预计实际耗时；排队时间无法保证。
所有新结果位于 outputs/followup-20261108-随机字符。模型、阈值、清单、旧预测和编码器文件执行前后核对哈希。
无软件安装步骤，不升级现有虚拟环境，不写入共享数据或旧输出。
新数据及缓存约需数GB空间；下载和旧数据RGB重叠审计只在CPU作业运行。

## 验证情况

- Python编译及bash语法检查通过。
- 加权AUROC（含并列分数、零权重）与独立成对比较算法100组随机对照通过。
- 配对cluster重采样：相同预测器差值区间严格为0的测试通过。
- 5305张模拟数据分析集成测试通过：90条指标、180条CI、9条家族汇总，结果ZIP成功。
- 官方文件名与1061×4组合逐项吻合，官方单张COCO图片HTTPS下载验证通过。
- 未在本机加载九个服务器checkpoint；实际GPU阶段由学校服务器执行后才能判定成功。

## 执行

在仓库根目录：`bash /解压目录/followup/submit.sh`。
脚本自行激活 `$HOME/.conda/envs/genimage`，无需重建环境。
提交输出含4个作业编号及独立输出目录，另存到 `$HOME/genimage-setup/followup-latest.txt` 供查询。
提交脚本只运行一次，避免重复排队。

成功依据：四作业均COMPLETED且ExitCode为0:0，输出目录status.json的finished为true。
最终results.zip不包含原始图片、特征缓存或模型权重；包含指标、CI、逐图logits、审计、脚本与日志。
